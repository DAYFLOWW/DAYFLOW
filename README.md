# DAYFLOW v5

Versión con nuevo diseño visual, widget de tarea actual/siguiente, horarios de trabajo y descanso, recordatorios no bloqueantes y configuración inicial para nuevos usuarios.

## Publicación
Sube `index.html`, `manifest.webmanifest`, `icon.svg` y `sw.js` a la raíz del repositorio de GitHub Pages y confirma los cambios.

## Privacidad y límites
Los datos se guardan en localStorage en el navegador del dispositivo. Exporta una copia de seguridad antes de borrar datos o cambiar de dispositivo. Los recordatorios internos requieren que DAYFLOW esté abierto; las notificaciones del sistema dependen del navegador y no están garantizadas cuando la app está cerrada.
